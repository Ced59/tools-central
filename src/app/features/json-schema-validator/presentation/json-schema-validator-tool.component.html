Mode d’emploi

Valider sans masquer les problèmes de données

1

Fournissez le contrat

Collez un schéma complet. Les références locales #/$defs/… fonctionnent ; aucune ressource distante n’est chargée.

2

Gardez les types exacts

Le moteur ne convertit pas « 42 » en 42, ne supprime aucune propriété et n’ajoute aucun défaut pendant le diagnostic.

3

Relisez la proposition

Les corrections utilisent seulement les valeurs default, examples, const, enum ou des ajustements bornés.
