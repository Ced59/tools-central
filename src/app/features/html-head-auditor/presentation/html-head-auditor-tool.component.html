Auditeur de head HTML

Contrôlez les métadonnées SEO, sociales, mobiles et multilingues d’un code HTML collé.

Analyse 100 % locale : aucun site n’est appelé et aucun code collé n’est exécuté.

1. Coller le head à contrôler

Un document HTML complet ou un fragment de head convient. Le parseur reste inerte.

Facultative, elle permet de comparer canonical, og:url et auto-référence hreflang. Aucune requête n’est envoyée.
Limite : 1 000 000 de caractères, 1 000 balises et 200 diagnostics.

4. Bien interpréter l’audit

Signaux, pas garanties

Une canonical reste un signal et un moteur peut reformuler le titre ou l’extrait selon la requête.

Responsive

width=device-width permet au navigateur d’adapter la largeur de mise en page à l’appareil.

hreflang

Chaque variante doit employer une URL absolue et inclure l’URL courante dans son groupe.

Traitement local

Le parseur lit du texte borné. Il n’insère pas le HTML dans la page, ne charge aucune ressource et ne lance aucun script.
