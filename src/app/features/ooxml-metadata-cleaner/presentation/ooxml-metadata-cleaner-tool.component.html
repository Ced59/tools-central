Aucun envoi : le document est contrôlé et reconstruit localement dans votre navigateur.

Ce qui est nettoyé

L’outil agit sur les propriétés standard du package OOXML et sur sa miniature. Le texte, les feuilles, les diapositives, les images et la mise en page sont conservés.

Ce qui reste à vérifier

Commentaires, auteurs de révisions, feuilles masquées, notes, macros et contenu visible ne sont pas supprimés. Inspectez le fichier final dans son application d’origine.

Vous avez un PDF ?

Le format PDF utilise une structure différente. Ouvrir le nettoyeur PDF dédié.
