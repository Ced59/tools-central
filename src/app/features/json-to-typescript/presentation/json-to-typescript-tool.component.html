Mode d’emploi

Obtenir un contrat utile, sans surinterpréter un exemple

1

Variez les échantillons

Incluez les objets avec et sans champs facultatifs, les valeurs nulles et les différentes formes de tableaux.

2

Choisissez fusion ou union

La fusion convient aux ressources semblables ; l’union préserve des variantes structurelles réellement distinctes.

3

Validez avec le contrat API

L’inférence accélère le démarrage, mais seule la documentation ou le schéma de l’API définit tous les cas possibles.
