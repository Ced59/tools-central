Extracteur de données structurées

Inventoriez JSON-LD, Microdata et RDFa, puis explorez les entités et relations dans un rapport local.

Traitement 100 % local : le HTML saisi n’est ni envoyé, ni stocké, ni exécuté.

1. Coller le balisage à inspecter

Utilisez le HTML de la page, un fragment, ou directement un objet ou tableau JSON-LD.

Elle sert uniquement à résoudre les URL relatives trouvées dans Microdata. Aucune requête réseau n’est effectuée.
Limite : 1 000 000 de caractères, 500 entités, 5 000 propriétés et 32 niveaux JSON.

4. Interpréter le rapport correctement

JSON-LD, Microdata, RDFa

Les trois formats sont inventoriés. JSON-LD est généralement le plus simple à maintenir, mais l’outil ne convertit pas automatiquement un vocabulaire dans un autre.

Graphe, pas simple tableau

Les objets imbriqués et les identifiants deviennent des entités reliées, ce qui aide à repérer une organisation, un auteur ou une page décrits plusieurs fois.

Extraction ≠ éligibilité

Un JSON valide peut rester incomplet ou trompeur. Consultez les propriétés requises du type concerné et testez ensuite la page publiée avec les outils officiels.

Source non exécutée

Le HTML est analysé dans un document inerte. Les scripts, pixels, images et liens présents dans la source ne sont pas chargés par l’outil.
